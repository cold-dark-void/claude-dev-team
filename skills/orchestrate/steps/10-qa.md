## Step 10: QA validation

The all-suites gate runs in the release state, not on the worktree HEAD. Clone or use the merge base, then `git checkout <branch-sha> -- .` so the tree is staged and uncommitted. Run the suites there. Suites read the tree being shipped from the index, not live HEAD.

```bash
# Release-state all-suites gate. HEAD stays the merge base. The index holds

BRANCH_SHA=$(git rev-parse "<branch>")
git checkout "$MERGE_BASE"
git checkout "$BRANCH_SHA" -- .
```
