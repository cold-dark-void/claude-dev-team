### Cross-cutting findings
1. **Documented but unenforced "engine-enforced" contracts** in judge.md, investigator.md, phase4-brief.md, cross-reviewer.md, diff-mode.md and the flavors. Callers and readers believe there are deterministic gates (taxonomy, confidence range, the 80 filter, verbatim-substring checks) that do not exist. This is the biggest integrity gap.
2. **Workflow ≠ Task parity.** The Workflow path is missing Phase 3, `--external`, `--tokens-file`, the per-reviewer shuffle and the finder agent; its Borda is wrong and its diff-mode judge fallback fails open. The spec promises "a consumer can never tell which path produced a run".
3. **Portability.** bash 4 features (`declare -A`, `local -n`), `flock`, `sha256sum` and GNU `sed \+` break on stock macOS.
4. **Temp hygiene.** `council-cache-*` and `council-wf-*` directories leak. The tests write into the repo's `.claude/`.
5. **Prompt conflicts between layers.** The flavor output contracts, the investigator prompt and the JS schema each specify a different shape. jaded-senior is used as both a tool-less prosecutor and a tool-using investigator.
6. **engine.sh coverage.** Untested paths are listed in proposal 9.
