### Cross-cutting findings
1. **Tier contradictions:** SPEC-003 tier table = agents frontmatter = AGENTS.md:60-73 = README:44-52 (all consistent). **install.sh:123-196 disagrees**, and so does pm.md:60 (escalate "to Opus" from Opus).
2. **Duplicated prompt bloat:** the output-intensity block (~20 lines) is copied into 9 agents and AGENTS.md:222-235 with no managed include. The memory include (~110 lines × 7 agents) re-derives `MROOT` four times per agent. Every behavioral spawn pays roughly 130 lines of repeated preamble.
3. **Fresh-shell variable bugs in agent fences:** project-init :455 (`$MROOT`), distiller :33-50 (`$MEMDB`, `$DIGEST`, `$NEW_ID`) and AGENTS.md :151 (ordering). Smoke can't catch these because agents/ is not scanned, and skill-lint's C1 rule doesn't cover agents/.
4. **Append-only contract violated:** project-init :148 (`cat >`) against the SPEC-004 comment in every protocol include.
5. **Security posture drift:** `/setup team` grants `Bash(*)` with no sandbox (project-init:50), while AGENTS.md:267 claims the sandbox is the boundary and README:245 claims `rm` prompts. Separately, "read-only" finder/debugger are enforced by prompt only (Bash is unrestricted).
6. **Two plugin-root resolvers:** the PDH stanza (AGENTS.md:92, 5 tiers) and the agent embed resolver (ic5.md:209-210, 2 tiers).
7. **CI gap (full test run in a scratch copy, as root, Linux):** 76 test scripts; 6 run in CI; 68 passed. Eight fail, which shows they rot outside CI:
   - Likely real drift:
     - `handoff/detached-stub-test.sh`: commands/handoff.md is 12096B, over its 12000B cap.
     - `orchestrate/router-static-test.sh`: T10 "02-scope.md bad-form".
     - `retro-gate/scheduled-retro-test.sh`: "Filter 2 missing from commands/retro.md".
     - `release-train/test-integration.sh`: "restore dirty".
     - `council/test-workflow-static.sh`: exit 1 with no FAIL line, probably a missing `node`, so it fails silently.
   - Likely environment:
     - `metrics/test.sh` #4 and `transcript-mirror/test.sh` M4: both are unwritable-path tests running as root.
     - `retro-gate/friction-capture-test.sh`: needs the generated `.claude/hooks/`.
   - Only 3 test scripts are referenced by `/release` gates (plugin-dir, test-bump-class, test-ship-history).
8. **Portability (macOS/BSD):** `sha256sum` (install-test), `timeout`/`rg`/`/opt/...` (probe), `\s` in ERE (install.sh:240); no macOS CI.
9. **Stale docs:** SECURITY.md versions, the scout-plugins command, the project-init `dontAsk`, the README opencode snippets, and the CC minimum version.
